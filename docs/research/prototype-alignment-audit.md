# TTLI_LMS — Prototype (11 screens) vs `apps/web`: alignment audit

**Scope:** Gap analysis between the approved interface prototype (11 screens: Landing, Podcast, Guest access, Catalogue, Programme detail, Checkout, Dashboard, Player, Assessment, Certificate, Manager) and the `apps/web` pages as of 2026-08-16 (before the alignment build). Produced by a read-only sub-agent; every claim was checked in the files cited. Companion to `enterprise-lms-ui-design.md` (the target) and the design-system port that followed.

Path shorthands: **W** = `apps/web`, **A** = `apps/api/src`.

## 0. Shared shell, tokens, fonts (pre-port state)

- **Tokens** (`W/app/globals.css`): all colour tokens, `--serif/--sans/--mono`, `--r`, `.eyebrow`, `.btn` (--primary/--ghost/--lg/--block), `.tag` (+ variants), `label.field`/`.input`, `.table-wrap table.data`, `.card` existed. **Missing:** `.btn--quiet/--locked`, `.bar`, and ~100 prototype component classes (`.site-head`, `.hero*`, `.ccard*`, `.article`, `.split*`, `.cat/.facets`, `.detail/.buybox`, `.checkout/.tabs/.callout/.bank/.dropzone/.summary`, `.dash/.stats/.continue/.rowlist`, `.playerlayout/.curric-rail/.lrow/.video/.watermark/.scrub/.reqs/.refusal/.foot-nav`, `.quizwrap/.qcard/.opt`, `.certpage/.certificate/.verify/.share`, `.mgr/.tenant-strip/.privacy-note/.tablewrap/.hidden-cell/.minibar`), `:root[data-theme=dark]`, `--shadow-3`. Net ~10 of ~110 classes present. → **Closed 2026-08-16 by the design-system port** (all classes added; forms/tables scoped to avoid fighting Tailwind utilities; `.tag` kept app variant; `.card` kept).
- **Fonts:** Charter stack defined and used on headings; not used for lead paragraphs/prices/stat numerals as the prototype does.
- **Header** (`W/components/site-header.tsx`): rendered nothing signed-out and only "email · Sign out" signed-in; no brand mark, nav, avatar or guest tag; landing had its own inline header with different nav items. → **Closed by the port**: `.site-head` with brand-mark (TTLI glyph or white-label `.tenant-logo` + "Powered by TTLI"), `.site-nav` (public: Courses / Executive Programmes / Live Workshops / Resources / For Organisations; learner: My learning / Catalogue / Workshops / Achievements; staff: + Admin), `.head-actions` (Sign in + Try a free lesson; guest tag + avatar; avatar + Sign out). Remaining data gap: `/auth/me` had no name or guest expiry (being added by the presentation API pass).

## 2. Notes from the design-system port (2026-08-16)

- `globals.css` rewritten with every prototype component class, sectioned like the prototype; token values unchanged (WCAG-tuned `--faint` kept). Forms scoped (`.fields label`, `.form-wrap > label`, `.panel > label`, `.two label`, and `.input`/`.fields input` etc.) because Tailwind v4 utilities live in `@layer utilities` and an unlayered bare `label { display:grid }` would beat every existing `className="flex"` label. Tables scoped to `.tablewrap`; `.table-wrap table.data` kept sharing the same th/td rules. `.btn--locked` deliberately not `disabled` (prototype semantics). Small-screen nav wraps and scrolls instead of hiding. `prefers-reduced-motion` block added; `.site-head` hidden in print.
- `site-header.tsx` rewritten to the `.site-head` structure; first-party vs white-label detected by tenant name (`TTLI|Themba Thandeka`) since the theme has no first-party flag; guest inferred from the guest role's permission set until `/auth/me` carries `is_guest`; `initialsFromEmail` exported. `layout.tsx` passes `tenantName`/`logoUrl` to the header.
